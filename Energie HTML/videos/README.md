# Dossier Videos - Migration Flash vers HTML5

## Situation
Les vidéos originales utilisaient Flash (fichiers .swf) qui n'est plus supporté par les navigateurs modernes.

## Solution implémentée
- **Lecteur vidéo HTML5** moderne et responsive
- **Remplacement automatique** des anciens lecteurs Flash
- **Design moderne** avec animations et messages informatifs

## Spécifications recommandées
- **Format** : MP4 (H.264)
- **Résolution** : 720p minimum
- **Audio** : AAC ou stéréo standard
- **Taille** : Compressé pour le web

## Comment ajouter les vidéos
1. Convertissez les fichiers .swf originaux en .mp4
2. Placez-les dans ce dossier `/videos/`
3. Le lecteur les détectera automatiquement

## Alternative
Si vous n'avez pas les fichiers vidéo, les pages affichent un message informatif avec des alternatives pour les étudiants.
